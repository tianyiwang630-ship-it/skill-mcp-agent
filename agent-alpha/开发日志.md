# 开发日志

## 2026-05-27

背景：需要让 agent-alpha 支持在对话中安装外部 skill，默认安装到项目 skill 目录，也能按当前 agent 实例的 workspace 安装 workspace 专属 skill。

关键更改：
- 新增外部 skill 安装器，支持本地目录、GitHub 目录、raw `SKILL.md` 和 zip 来源。
- 新增 `agent-alpha skill install/list/remove` CLI 子命令。
- `SkillLoader` 支持同时读取 project skills 和 workspace skills，workspace 同名 skill 优先。
- 系统提示词增加 project/workspace skill 路径和安装目标规则。

补充修复：
- 检查 Agent Reach 安装链路后，发现裸 `pip install` 会装到用户 Python 目录，和 agent-alpha `.venv` 不一致。
- 沙箱增加 `uv pip install`、`uv tool install`、`pipx install` 的识别，改为请求用户确认而不是直接拒绝。
- 系统提示词增加 Python 包安装环境提示，要求优先绑定 agent-alpha `.venv` Python。
- 启动脚本会在 `.venv` 缺少 `pip.exe` 时用 `ensurepip` 补齐，并导出 `AGENT_ALPHA_PYTHON`、`AGENT_ALPHA_PROJECT_ROOT`、`PYTHONNOUSERSITE`、`PIP_REQUIRE_VIRTUALENV`，减少裸 `pip` 误装到外部 Python 的概率。
- 沙箱策略调整为实用优先：常见环境诊断命令自动允许，安装/venv/外部工具初始化命令请求确认，未知命令请求确认，高危命令仍直接拒绝。
- Windows 上 bash 工具默认优先使用 PowerShell，减少 Git Bash 对 Windows 路径和环境变量的兼容问题。
- 补充 PowerShell 高危命令拦截，包括 `Remove-Item -Recurse -Force`、`Stop-Computer`、`Restart-Computer`、`Set-ExecutionPolicy`、`Invoke-Expression`、注册表/ACL/防火墙相关命令。
